# Malva UI — Missing Components

Components to implement using the `create-library` skill, one at a time.

## Critical

- [x] `tooltip` — lightweight floating tooltip overlay triggered by hover/focus, appearing above/below/left/right a target element with configurable delay and arrow pointer
- [x] `textarea` — multiline text input form control extending FormControlBase with auto-resize mode, min/max rows, character count, and reactive forms support via CVA
- [x] `alert` — inline feedback banner supporting info/success/warning/danger severity levels, dismissible mode, icon slot, title and description content projection
- [x] `menu` — dropdown action menu with MlvMenuTrigger, MenuItem, MenuSeparator, keyboard navigation, nested submenu support
- [x] `breadcrumb` — navigation breadcrumb with configurable separator, overflow truncation for long paths, and router integration
- [x] `skeleton` — content placeholder with pulse animation supporting text, circle, and rectangle variants and configurable dimensions
- [x] `file-upload` — drag-and-drop file upload zone with file type/size validation, multi-file support, preview thumbnails, and reactive forms CVA integration

## Important

- [x] `divider` — horizontal and vertical separator component with optional label slot
- [x] `empty-state` — structured no-data placeholder with illustration/icon slot, title, description, and primary action button slot
- [x] `progress` — standalone determinate and indeterminate linear/circular progress bar with label and percentage display
- [x] `stepper` — multi-step wizard component with horizontal and vertical orientation, step validation states, and navigation controls
- [x] `date-range-picker` — date range selection input using two calendar instances for start and end date with reactive forms support
- [x] `time-picker` — time input combining hour/minute/second selectors .with AM/PM toggle and reactive forms CVA
- [x] `tree` — hierarchical data tree component with expand/collapse nodes, checkbox selection mode, lazy loading support, and keyboard navigation

## Nice to Have

- [x] `split-pane` — resizable split panel layout supporting horizontal and vertical splits with configurable min/max sizes and drag handle
- [x] `timeline` — vertical timeline for activity feeds and audit logs integrating avatar, badge, and chip components for rich event display
- [x] `color-picker` — HSL/HEX/RGB color selection with hue slider, saturation/lightness canvas, opacity control, and reactive forms CVA
