# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. Please read it — the summary below does not replace it.

## In short

Everyone taking part in this project — issues, pull requests, discussions,
reviews — is expected to treat others with respect. Assume good faith, critique
the work rather than the person, and accept that maintainers make the final call
on scope and direction.

Unacceptable behaviour includes harassment, personal or political attacks,
publishing someone's private information, and sustained disruption of
discussions.

## Scope

This applies in every project space, and whenever someone is representing the
project in public.

## Reporting

Report unacceptable behaviour to the maintainers privately, through GitHub's
**Report content** flow on the offending comment, or by contacting the
repository owner directly.

> **Maintainers:** add a dedicated contact address here before making the
> repository public. The Contributor Covenant expects a named reporting channel,
> and GitHub's generic reporting flow is a weaker substitute.

Reports are handled confidentially. Maintainers who do not act in good faith on
a report may face consequences decided by the project's leadership.

## Enforcement

Maintainers may remove, edit or reject comments, commits, issues and pull
requests that do not follow this code of conduct, and may temporarily or
permanently ban any contributor for behaviour they judge inappropriate.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
