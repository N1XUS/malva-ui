## Basic Dialog (Medium)

Wrap the content in `<ng-template [(mlvDialog)]>`; the template is created only while open. `<mlv-dialog>` is the surface, `mlv-dialog-header` / `mlv-dialog-body` / `mlv-dialog-footer` are its parts, and any `[mlvDialogClose]` button closes with an optional result (`(mlvDialogClosed)`).
