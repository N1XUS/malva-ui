---
title: With Label
---

Project text content into `mlv-divider` to display a centered label. The label is also the separator's accessible name: assistive technology gets a separator named "OR" instead of an unnamed one. To name it differently — a translated string, a heading id per row — bind `ariaLabel` or `ariaLabelledBy`. Keep the label to text: a link or button inside a divider is hidden from assistive technology.
