---
title: Basic Usage
---

`button[mlvIconToggle]` enhances a native `<button>` with a two-way `pressed` model reflected as `aria-pressed`. There is no background in any state — the toggle reads entirely through the projected icon: outlined at rest, a faint tint on hover, and a full `currentColor` fill when pressed.

Project exactly one Lucide `<svg>` and give the button an accessible name.
