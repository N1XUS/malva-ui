---
title: Tone — the favourite-star pattern
---

An optional `tone` (`MlvTone`) recolours only the **pressed** glyph, never a surface. This is the exhibit-B replacement pattern from the visual-language spec's composition recipes: a row-level favourite star, bound one-way with an explicit handler so the caller's data stays the single source of truth.

Rest and hover stay neutral regardless of `tone` — only the filled, pressed star picks up `--mlv-text-warning`.
