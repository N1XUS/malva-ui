Application styling

Tailwind CSS v4

Use Malva UI's colors, spacing, typography, borders, radii, and shadows with Tailwind utility classes. The adapter maps utilities to the same runtime tokens used by Malva components, so themes stay in sync.

Install in one command {{ installCommand }}

What this adds

@malva-ui/tailwind is an optional application styling layer. It does not replace the Malva component stylesheet, and it emits no precompiled utility bundle. Tailwind CSS v4 generates only the utilities your project uses.

Available variables and class names

The adapter exposes namespaced Tailwind theme variables. The class prefix tells you which CSS utility family consumes each variable.

Malva UI Tailwind v4 theme namespaces
Theme variables Class patterns Examples
--color-mlv-* bg-*, text-*, border-* bg-mlv-primary-500, text-mlv-content
--spacing-mlv-* p-*, m-*, gap-*, sizing p-mlv-4, gap-mlv-2, mt-mlv-6
--radius-mlv-* rounded-* rounded-mlv-card, rounded-mlv-full
--shadow-mlv-* shadow-* shadow-mlv-raised, shadow-mlv-floating
--font-mlv-* font-* font-mlv-code, font-mlv-display, font-mlv-mono
--font-weight-mlv-* font-* font-mlv-medium, font-mlv-bold
--text-mlv-* text-* text-mlv-heading-h2, text-mlv-body-m
--leading-mlv-* leading-* leading-mlv-body-m, leading-mlv-relaxed

For code and technical content, use font-mlv-code. It maps to --mlv-font-family-code and prefers Fira Code, then JetBrains Mono, before falling back to a system monospace font.

Colors

Palette families are available at stops 50 through 950: primary, secondary, accent, neutral, success, warning, danger, and info. Semantic names cover surfaces, content, interactive states, on-color text, and borders such as bg-mlv-surface-raised, hover:bg-mlv-primary-hover, and border-mlv-focus.

Spacing

The spacing scale contains 0, px, half steps through 3.5, and the larger steps 4, 5, 6, 8, 10, 12, and 16. Use these as single-value utility inputs. Malva's --mlv-padding-* variables are two-value pairs and are intentionally not mapped into Tailwind spacing.
