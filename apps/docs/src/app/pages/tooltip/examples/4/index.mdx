---
title: Advanced
---

Advanced tooltip patterns: **Icon-only buttons** should use `aria-label` for primary accessibility and `[mlvTooltip]` as a secondary visual cue. Use `[tooltipDelay]` to set a custom delay in milliseconds. Set `[tooltipArrow]="false"` to hide the arrow pointer. Set `[tooltipDisabled]="true"` to conditionally suppress the tooltip.
