---
title: Basic Date Range Picker
---

`mlv-date-range-picker` renders a trigger that opens a dual-calendar popup. The user selects a start date on either calendar, then an end date to complete the range. Clicking **Apply** commits the selection; **Clear** resets it.

The component's signal-control contract also works with Angular's `[(ngModel)]` for quick two-way binding. The value shape is `{ start: Date | null, end: Date | null }`. For reactive-forms integration, see Example 4.
