## Dark Application Chrome With an Attached Page Canvas

`mlv-page-shell` supplies the dark chrome and stable tracks that join an existing action bar, collapsible sidebar, and attached `main[mlvPage]` surface. The top bar is composed entirely from `mlvActionBarLogo`, `mlvActionBarActions`, `mlv-toolbar`, `mlv-search-field`, `mlv-badge`, `mlv-avatar`, and `mlvButton`; consumer CSS is only needed for product-specific finishing touches. The Page header composes `mlvBreadcrumb` and `mlv-tab-group`; the primary and inspector content use `mlv-card`. `mlv-page-content` keeps the inspector beside the work area until its own container becomes constrained.

Everything responsive here answers to the shell's **own width**, not the viewport — an application shell is rarely the whole screen, and this one is a box inside a documentation page. A single `ResizeObserver` on the preview drives both steps: below 760px the topbar search becomes an icon that opens its full-screen overlay, and below 560px the sidebar switches to `mode="offcanvas"` and opens as a drawer over the canvas, with a menu button in the top bar to reach it.
