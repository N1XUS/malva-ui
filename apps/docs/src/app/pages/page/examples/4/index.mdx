---
title: Responsive end pane
description: One details template moves between an inline aside and a modal Drawer without splitting its open or focus lifecycle.
---

Bind a native Malva button with `[mlvPageEndPaneTrigger]`, then provide exactly
one `<ng-template mlvPageEndPaneContent>`. Above `collapseBelow`, the pane
occupies the Page shell's trailing track. Below it, the same template renders
once in a modal Drawer and the host stops reserving inline width.

`opened` remains one logical state throughout breakpoint migration. A real
close—button, Escape, backdrop, or model update—restores the element that opened
the pane and emits `afterClosed` only after the active renderer is gone.

Static trailing content remains supported through `[mlvPageEndSidebar]`; use
`mlv-page-end-pane` when the trailing region needs responsive modal behavior.
