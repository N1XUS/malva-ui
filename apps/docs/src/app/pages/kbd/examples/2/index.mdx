## Supported Keys

The `keys` input accepts any of the canonical key names below. Unknown strings are uppercased and displayed verbatim.

| Key name | Mac label | Win/Linux label |
|---|---|---|
| `cmd`, `command`, `meta` | `⌘` | `Ctrl` |
| `ctrl`, `control` | `⌃` | `Ctrl` |
| `shift` | `⇧` | `Shift` |
| `alt`, `option` | `⌥` | `Alt` |
| `enter`, `return` | `↵` | `Enter` |
| `backspace` | `⌫` | `Backspace` |
| `delete` | `⌦` | `Del` |
| `escape`, `esc` | `⎋` | `Esc` |
| `tab` | `⇥` | `Tab` |
| `space` | `␣` | `Space` |
| `up` / `down` / `left` / `right` | `↑` / `↓` / `←` / `→` | `↑` / `↓` / `←` / `→` |
