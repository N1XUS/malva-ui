## Timer, Hover Pause & Non-Closable

`displayTime` controls how long (in ms) the toast stays visible. Setting `pauseOnHover: true` (the default) pauses the timer while the cursor is over the toast and restarts it when the cursor leaves. Set `closable: false` to hide the X button — the toast will only dismiss when the timer expires. The returned `MlvToastRef` can also dismiss it programmatically at any time.
