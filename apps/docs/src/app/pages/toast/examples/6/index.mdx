---
title: Shape and Tone Icon
---

`shape: 'pill'` renders a fully rounded, content-hugging bar instead of the default rectangle. `icon: true` adds the icon derived from `tone` — `success`, `warning`, `danger`, and `info` each map to a Lucide glyph, while `tone: 'default'` has none, so the flag does nothing there.

There is no icon-name option on the config: the built-in icon is always tone-derived. Template and component content passed to `open()` owns its own leading icon through `[mlvToastIcon]`, and the built-in one is suppressed for those branches so the two never compete.
