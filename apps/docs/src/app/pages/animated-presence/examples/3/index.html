Overview

A high-level summary of the component status and recent activity. Each panel mounts with an enter animation and leaves with an exit animation before being removed from the DOM.

Settings

Configuration options and preferences. The leave animation plays in full before this panel is destroyed — unlike standard @if which removes the DOM node immediately.

Logs

Recent activity log entries. Combine with custom enter/leave classes to use any animation from @malva-ui/styles.
