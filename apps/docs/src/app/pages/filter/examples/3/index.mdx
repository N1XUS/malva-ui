---
title: Smart Filter Bar
---

Definitions are the source of truth for labels, editors, operators, defaults, required fields, and visibility. Required fields remain visible and block execution while empty. Active fields cannot be hidden until their conditions are cleared, so the query never contains an invisible filter.

The bar composes search plus structured conditions into an execution payload that deeply copies plain data (arrays, plain objects, `Date`, `Map`, `Set`) and passes class instances such as a Dayjs or Luxon value through by reference, so their methods keep working. A shared value is the same object in the bar's state and in every later payload, so treat it as immutable: mutating one in place (a Moment is mutable) changes what the bar holds and emits next. Multiple conditions use OR by default unless a definition supplies `conditionStrategy`. The modal available-filters manager stages changes so Cancel can roll them back.
