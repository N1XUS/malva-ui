## Resizable Filter Panel

A left drawer that behaves like a persistent side panel: `resizable` with **no** `snapPoints` gives free drag-to-resize, `minSize` / `maxSize` clamp the width (18–40rem here), `defaultSnap` sets the opening width as a viewport percentage, and `[hasBackdrop]="false"` keeps the page visible behind it. The header's badge tracks the live filter count next to the close button; the footer commits or resets the form.
