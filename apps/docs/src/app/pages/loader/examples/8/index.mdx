## Progress Hint

Set `[showHint]="true"` to display the calculated percentage alongside the loader. The hint is only shown in **determinate** mode — it is hidden when `[indeterminate]="true"`.

For the **bar** variant the percentage label appears directly above the track, right-aligned. For the **circle** variant it is centered inside the ring. Both positions are driven purely by layout (no JavaScript), so the hint updates in sync with the progress value.
