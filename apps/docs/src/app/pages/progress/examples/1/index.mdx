---
title: Bar — Basic
---

The bar variant renders a horizontal progress track that fills from left to right. Bind `[value]` to a number between `0` and `100`. The fill transitions smoothly when the value changes thanks to a CSS transition that activates after the first render.

The component always exposes `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` for screen readers. Use `ariaLabel` to provide a meaningful description of the operation being tracked.
