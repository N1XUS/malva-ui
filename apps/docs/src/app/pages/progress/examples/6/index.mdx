---
title: Circle — Sizes and Percentage
---

Combine `showPercentage` with the circle variant to display the value inside the ring. The label slot renders below the ring and is ideal for resource or metric names. Here each ring also sets `ariaLabel` ("CPU usage" around the visible "CPU"): an explicit `ariaLabel` wins over the label slot, so keep the visible text inside it. All three size variants (`s`, `m`, `l`) scale the diameter and the centred text proportionally.
