## Masked Mode (Password)

Set `type="password"` to mask each character as it is typed — useful for numeric PINs where security matters. The component supports all three standard input types:

| `type` | Use case |
|--------|----------|
| `"text"` | OTP / verification codes (default) |
| `"password"` | Security PINs — characters hidden |
| `"number"` | Numeric-only on mobile keyboards |
