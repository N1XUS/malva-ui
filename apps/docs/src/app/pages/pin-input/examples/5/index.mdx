## States and Customisation

- **`disabled`** — all cells become non-interactive and visually dimmed. Passing a pre-filled `ngModel` or `formControl` value still renders the characters.
- **`placeholder`** — the character shown inside each empty cell (default `·`). Use `"0"` for numeric PINs where a digit hint is more intuitive.
- **`type="number"`** — sets `inputmode="numeric"` which triggers the numeric soft keyboard on iOS and Android, keeping the desktop experience unchanged.
