---
title: Popup Mode
---

Popup mode uses `mlv-color-picker-popup` as an input-like CSS color field. Focus
the text input or click its rounded color swatch to open the popover.
Valid CSS colors and custom-property references such as `var(--brand-color)`
are accepted; invalid drafts roll back to the last valid value. By default,
changes commit when the input blurs or the popover closes. Add `live` to publish
every valid edit immediately. Click the backdrop or press `Escape` to close the
panel.
