---
title: Value tooltips
description: Show live thumb values and customize their rendered text
---

Enable `tooltip` to show the current value while a thumb is hovered, dragged,
or keyboard-focused. By default, the numeric value is rendered.

Add an `mlvSliderTooltipDef` template to format the text. Its implicit value is
the current number; `thumb` is `'value'` for a single slider or `'min'` /
`'max'` for a range. Keep custom tooltip content short and non-interactive.
