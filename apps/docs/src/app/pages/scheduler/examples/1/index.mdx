## Views and model binding

`mlv-scheduler` renders one of three views — `month`, `week`, `day` — chosen with the toolbar's
segmented control or the `view` model. `date` is the anchor date of the visible range; `events` is a
plain array model: the scheduler never mutates the objects you pass in. Every drag, resize or keyboard
move writes a **new array** through `[(events)]` and emits the matching output, so the parent keeps a
single source of truth. Give the host a block size — the views fill it and scroll inside it.
