---
title: Basic inline usage
---

`<mlv-copy-to-clipboard>` wraps any inline content. By default, its projected
text becomes what is copied. The component reads as regular prose until the
user hovers or focuses it — at that point a subtle background tint appears
and a small copy icon fades in at the trailing edge.

```html
<p>
  Your API key is <mlv-copy-to-clipboard>sk_live_abc123xyz</mlv-copy-to-clipboard>.
</p>
```
