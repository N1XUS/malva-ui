---
title: Vertical Scroll
---

Wrap any overflowing content in `<mlv-scrollbar>`. The component hides the native scrollbar and renders a slim custom thumb on the right edge. The host element must have a defined height — set it with a CSS class or inline style.

Hover over the scrollable area to see the thumb at full opacity. The thumb opacity is reduced at rest to keep the UI uncluttered.
