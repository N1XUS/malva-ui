---
title: Tones
---

`mlv-status-indicator` renders a `0.25rem` dot. The `tone` input accepts the
same eight semantic values as `mlv-badge` / `mlv-chip` — `default`, `primary`,
`secondary`, `accent`, `success`, `info`, `warning`, and `danger` — each mapping
to a solid `--mlv-*` fill token. Here each dot carries an `ariaLabel` because
the colour is the only thing conveying its meaning.
