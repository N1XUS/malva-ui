---
title: Click outputs
---

`(groupClick)` emits the full `MlvAvatarGroupMember[]` when the user clicks anywhere on the group. `(overflowClick)` emits only the hidden members when the user clicks the `+N` chip — propagation is stopped so the host click does not also fire.

Add `interactive` (or `[interactive]="true"`) to show a pointer cursor on the host, signalling the group is clickable.
