---
title: Basic stacked group
---

Render a `mlv-avatar-group` by passing an array of `MlvAvatarGroupMember` objects via the `[members]` input. Each member requires only a `name` — initials and a deterministic background color are derived automatically.

The group stacks avatars with a negative-margin overlap and draws a subtle ring around each avatar so overlapping edges remain visually distinct on any background.
