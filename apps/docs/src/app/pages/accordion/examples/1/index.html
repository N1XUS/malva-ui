Malva UI is a modern Angular component library built on a design-token driven system. It provides accessible, themeable components with full dark mode support out of the box. Yes. Every component targets WCAG 2.1 AA. The accordion is built on the @angular/aria accordion pattern, which owns the roles, aria-expanded/aria-controls wiring, and keyboard navigation. Light and dark themes ship out of the box, driven entirely by --mlv-* CSS custom properties.
