## Scroll strategy

The `scrollStrategy` input controls what happens to the popup when the user scrolls the page while the popup is open.

- **`reposition`** (default) — the overlay follows the trigger as the page scrolls, staying anchored to it at all times.
- **`close`** — the overlay closes the moment scrolling is detected, keeping the UI clean.
- **`noop`** — the overlay stays at its original screen position and does not move with the trigger.

Scroll down inside the demo area after opening a popup to see the difference.
