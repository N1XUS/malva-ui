Overview

Overview

A appearance="boxed" group whose tabs are routerLinks. The active tab is derived from the URL via Router.isActive — watch the address bar update to ?demoTab=overview. Tabs are deep-linkable and respond to browser back / forward.

Activity

Activity

The header items are real links — middle-click a tab (or use "Open in new tab") and it opens at its own URL.

Settings

Settings

Activating a tab calls router.navigateByUrl(); the group never sets activeTab directly, so the URL stays the single source of truth.
