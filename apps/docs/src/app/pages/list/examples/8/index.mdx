## Settings Rows With Switches

Grouped, inset settings sections built from `mlv-list-item-group`. Toggleable
preferences pair a leading icon with a title/description and a trailing
`mlv-switch`; navigational rows (Quiet hours, Email digest) show a current
value plus a chevron instead. Every switch gets an `ariaLabel` matching its
row's title so it carries its own accessible name without repeating the
visible text.
