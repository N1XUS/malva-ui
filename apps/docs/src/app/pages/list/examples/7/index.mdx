## Conversation Rows

A messaging-style list pairs a leading avatar with a bold title and a muted,
truncated preview line — the same compact shape used for chat and mail rows.
Unread state is carried by a single restrained accent, a trailing count badge,
rather than colored borders or saturated avatar fills, so a busy inbox still
reads calmly. Avatars derive their fallback color from
`[name]` only — never an explicit saturated `[color]` — to keep the row's
accent budget spent on the one badge that matters.
