## Inbox (Unread + Reveal Actions)

An Apple Mail-style inbox built from the `variant="inset"` list, the `unread`
state on `mlv-list-item`, and `revealOnHover` trailing actions. Unread rows
render the sender in semibold with a leading accent dot; hovering (or tabbing
into) a row reveals the reply / archive / delete controls without cluttering
the resting state.
