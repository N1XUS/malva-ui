## Open on hover or focus

`triggerOn` takes the same values as the popup trigger — `click`, `hover`, `focus` — one or several. The trigger's click (and Enter/Space, and a touch tap) always toggles, so the menu button stays operable whatever is listed; the other types add ways to open. `hover` opens as soon as a mouse or pen pointer enters the trigger and closes a moment after the pointer has left both the trigger and the actions, so it can cross the gap to an action. `focus` opens when the trigger is focused (Tab onto it) without moving focus into the menu, and closes when focus leaves the trigger and the actions.
