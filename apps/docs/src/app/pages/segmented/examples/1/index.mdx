---
title: Basic
---

`mlv-segmented` holds native `<button mlvSegmentedItem value="…">` children. Bind the selection with `[(value)]`; the pill slides to whichever item's `value` matches. Items are plain buttons — project icons, text and badges freely.

Keyboard: `Tab` reaches the selected segment, `←`/`→` (or `↑`/`↓`) move **and select**, `Home`/`End` jump.
