---
title: Custom Controls
---

An action does not have to be a button. Any element carrying `[mlvSwipeAction]` is placed on the row — here an `mlv-switch` and a circular `mlvButton`. The switch keeps its state on the row: `closeOnActivate="false"` stops the row from closing after each toggle, so the contact can be muted and unmuted without re-swiping, while the delete button closes it as usual.

A plain host gets no native `type` written onto it either; only a `<button>` host defaults to `type="button"`.
