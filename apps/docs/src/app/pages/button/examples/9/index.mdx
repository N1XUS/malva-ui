---
title: Close button
---

`mlv-button-close` provides the standard X-icon action with a circular, transparent button by default. It uses the shared `mlvDensity` directive and supports every density: `tight`, `compact`, `comfortable`, `spacious`, and `airy`.

At each density, its dimensions match a regular icon-only `mlvButton`. The transparent icon uses a neutral secondary color at rest and strengthens to the theme's primary text color on hover or press, adapting automatically in light and dark modes.
