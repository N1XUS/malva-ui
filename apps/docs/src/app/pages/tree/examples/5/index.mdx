## Custom Node Template

Supply a `[mlvTreeNodeDef]` template to fully customize how each node is rendered. The template receives a `$implicit` context with the `MlvFlatTreeNode` (which includes the original `MlvTreeNode`, its `depth`, `isExpanded`, and `hasChildren` flags). The expand toggle, indentation, and checkboxes are still managed by the tree — only the content area is replaced.
