---
title: Basic Menu
---

A basic dropdown menu triggered by a button. The panel is rendered in a CDK overlay via `mlv-popup` and uses `mlv-list` for item layout. Use `(itemClick)` on each `mlv-menu-item` to handle actions, and `<mlv-divider muted />` (or `<mlv-menu-separator />`) to visually group related items.
