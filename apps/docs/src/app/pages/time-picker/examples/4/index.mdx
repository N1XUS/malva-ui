---
title: Reactive Forms Integration
---

`mlv-time-picker` implements Angular's signal-control contract and works seamlessly with reactive forms. Use `formControlName` inside a `FormGroup` or pass a `FormControl` directly via `[formControl]`.

Call `control.disable()` / `control.enable()` to toggle the disabled state programmatically — the component reflects it visually by reducing opacity and disabling scroll interaction on all columns.
