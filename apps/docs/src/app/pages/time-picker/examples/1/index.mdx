## Basic — 24-hour mode

The default time picker displays **hours** (0–23) and **minutes** (0–59) as scrollable columns. Scroll or use **Arrow Up / Arrow Down** keys to change values. The component emits a time string in `HH:mm` format.

Bind to `[value]` and `(valueChange)` for two-way data binding, or use `[formControl]` for reactive forms integration.
