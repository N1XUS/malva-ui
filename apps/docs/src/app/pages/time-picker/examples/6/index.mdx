## Validation States

The time picker supports five visual states via the `state` input: `default`, `success`, `warning`, `error`, and `info`. Each state changes the border color of the picker container to provide immediate visual feedback.

Pair `state` with `message` to show a descriptive validation message below the picker. This pattern integrates naturally with Angular's reactive forms validation — derive the state from your form control's validity and pass the appropriate message string.
