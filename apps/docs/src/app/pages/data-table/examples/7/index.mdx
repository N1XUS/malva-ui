---
title: Column groups (multi-row headers)
---

Pass `[columnGroups]` to render a two-tier header. Columns belonging to a group share a spanning header cell (e.g. "Q1 2026"). Standalone columns like Department, HC, and YoY Growth automatically span both rows with `rowspan="2"`. Useful for financial reports, comparison tables, or any layout where columns belong to logical categories.
