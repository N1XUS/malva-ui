---
title: Reserved for a call to action
---

A solid `mlv-badge` fill is reserved for a primary call to action or a count
badge on a navigation item — nowhere else. `tone` accepts one of eight
semantic values — `default`, `primary`, `secondary`, `accent`, `success`,
`info`, `warning`, or `danger` — but only `primary` and `danger` render solid
below; every other tone renders `muted`, the calmer everyday form used for
inline labels and tags (see the next example).
