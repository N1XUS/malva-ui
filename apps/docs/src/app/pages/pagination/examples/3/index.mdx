---
title: Collapsed page runs
---

Beyond nine pages the strip elides the middle: one corner page on each side, two pages either side of the current one, and an ellipsis where a run was removed. Each ellipsis renders as a small number field — type a page and press Enter to jump there; out-of-range values are ignored. The collapsing is driven by the page count, not the container width, so it behaves identically at every viewport size.
