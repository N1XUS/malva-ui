## Feedback

- [feedback_verbose_build.md](feedback_verbose_build.md) — Use `yarn nx run <lib>:build --verbose` when build fails to surface detailed errors (e.g. incorrect SCSS mixin import paths)
- [feedback_exports_and_ui.md](feedback_exports_and_ui.md) — Always `export * from`, never `export { X }`; use @malva-ui components over custom UI; use Lucide directive form (`<svg lucideX />`) for static icons
