# Docs Page: Button Group

> **Keep this file up to date.** Whenever examples are added, removed, or changed for this page, update this document.

## Route

- **Path:** `/button-group`
- **Component:** `ButtonGroupPageComponent` (`apps/docs/src/app/pages/button-group/index.ts`)

## Overview

Joins related buttons into one visual set and optionally supplies their shared variant.

## Examples

| #   | Title          | What it demonstrates                                                |
| --- | -------------- | ------------------------------------------------------------------- |
| 1   | Shared variant | Every labeled variant inherited from separate button groups         |
| 2   | Child override | A labeled local button variant taking precedence over the group     |
| 3   | Density        | Labeled connected groups rendered at all five button density levels |

## Libraries Used

- `@malva-ui/core/button`
