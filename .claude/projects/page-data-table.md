# Docs Page: Data Table

> **Keep this file up to date.** Whenever examples are added, removed, or changed for this page, update this document.

---

## Route

- **Path:** `/data-table`
- **Component:** `DataTablePageComponent` (`apps/docs/src/app/pages/data-table/index.ts`)

## Overview

A feature-rich data table with global search; toolbar, external, Smart Filter Bar, or per-column filtering; pinned columns; column resizing; tree rows; editing; selection; visibility controls; loading; summaries; and paged, infinite, or virtual scrolling.

## Libraries Used

- `@malva-ui/core/data-table` — primary component library for this page
- `@malva-ui/core/search-field` — composed internally for global table search in example 16
- `@malva-ui/core/filter` — standalone filters and Smart Filter Bar in examples 17–18
- `@malva-ui/core/pagination` — integrated pagination component
- `@malva-ui/core/badge` — status and priority badges in examples 5, 6, 8, 9; rendered by the data table itself for `tone` columns in example 21
- `@malva-ui/core/empty-state` — default error block in example 20 (rendered by the data table itself)
- `@malva-ui/core/avatar` — assignee avatars in example 8
- `@malva-ui/core/chip` — label chips in example 8
- `@malva-ui/core/input` — inline edit fields in example 6
- `@malva-ui/core/button` — density switcher in example 9, loading trigger in example 10, failure/retry triggers in example 20, projected Export action in example 23
- `@malva-ui/core/loader` — loading overlay in example 10
- `@malva-ui/core/checkbox` — row selection checkboxes in example 11 (rendered by the data table itself)
- `@malva-ui/cdk/infinite-scroll` — `MlvInfiniteScroll` used internally by `paginationMode="infinite"` in example 14
